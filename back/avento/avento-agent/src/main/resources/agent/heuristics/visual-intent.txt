# Termos que separam três pedidos visuais que se parecem e não são a mesma coisa:
# protótipo de interface (vira HTML), mockup de produto (vira imagem) e
# implementação de código (não vira nem um nem outro).
#
# Um termo entre aspas preserva os espaços das bordas: " ui " casa a palavra
# isolada, enquanto ui casaria dentro de "build", "gui", "quiz".
